# Quiz DOM

A programming quiz made with plain HTML, CSS and JavaScript, to practice DOM manipulation. Questions are in Portuguese.

## How it works

- Questions and answers live in a JavaScript array
- Answer buttons are created on the fly for each question
- Right and wrong answers are highlighted, then the next question loads
- At the end you see your score and can play again

## Running

No build step. Open `index.html` in the browser.
